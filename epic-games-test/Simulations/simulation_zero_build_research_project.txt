STEP 2.1: IDENTIFY TARGETING DEPENDENCY
--------------------------------------------------------------------------------

Reference: Framework, Lines 415-461

Target Population: Players who have played Zero Build mode at least once

    Criterion                  Field                Source          Logic
    ──────────────────────────────────────────────────────────────────────────
    Has ZB playtime            zb_total_hours       Telemetry       > 0
    Active in last 30 days     last_active_date     Player DB       >= 30 days ago
    Has email opt-in           email_opt_in         CRM             = TRUE
    Not surveyed recently      last_survey_date     Survey tracker  >= 30 days ago
    Account active             account_status       Player DB       = 'active'

Targeting SQL (for Databricks):

    SELECT 
        p.player_id,
        p.email,
        p.region,
        p.platform,
        s.player_type,
        t.zb_total_hours,
        t.build_total_hours,
        CASE 
            WHEN t.build_total_hours = 0 THEN 'ZB Only'
            ELSE 'Plays Both'
        END as mode_preference
    FROM player_base p
    JOIN player_segments s ON p.player_id = s.player_id
    JOIN telemetry_summary t ON p.player_id = t.player_id
    WHERE 
        t.zb_total_hours > 0
        AND p.last_active_date >= CURRENT_DATE - INTERVAL 30 DAYS
        AND p.email_opt_in = TRUE
        AND p.account_status = 'active'
        AND (p.last_survey_date IS NULL OR p.last_survey_date < CURRENT_DATE - INTERVAL 30 DAYS)
    ORDER BY RANDOM()
    LIMIT 25000;

    from scipy import stats
    
    pdf = df.toPandas()
    casual = pdf[pdf['player_type'] == 'casual']['Q5'].astype(float)
    competitive = pdf[pdf['player_type'] == 'competitive']['Q5'].astype(float)
    
    print(f"Casual mean: {casual.mean():.2f}")
    print(f"Competitive mean: {competitive.mean():.2f}")
    
    t_stat, p_value = stats.ttest_ind(casual, competitive)
    print(f"T-statistic: {t_stat:.2f}")
    print(f"P-value: {p_value:.6f}")
    
    if p_value < 0.05:
        print("Statistically significant difference ✓")
