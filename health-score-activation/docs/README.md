## `docs/` – Conceptual documentation

Use this folder to capture **all non-SQL context** for the activation health score project. This keeps domain knowledge close to the queries.

### Files

- `concepts.md` – core concepts (activation journey, health score, Lock & Key, CS buckets).
- `metrics.md` – metric definitions and viability status per milestone.
- `sql_playbook_best_practices.md` – SQL and performance practices for DBeaver + Metabase.
- `references/` – SQL query reference patterns and activation_health_score.yml spec (documentation only).

The goal is that someone new to Suflex can read `docs/` and understand **what** the queries do and **why**, before looking at the SQL.
